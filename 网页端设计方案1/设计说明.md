# 喵掌柜 · 网页端设计方案1 —— 设计说明文档

> 产品：喵掌柜 · 摄影写真预约系统（商家后台 + 顾客自助下单）
> 技术栈：Vue 3 + Element Plus
> 风格基调：**日系温暖 · 珊瑚红 · 可爱简洁 · 中度磨砂半透明**
> 本方案依据《设计需求文档》与主题图（扁平珊瑚红招财猫）产出，所有数值均为已敲定值。

---

## 一、设计基调与风格解读

主题图是一只**扁平色块**的珊瑚红招财猫：纯色猫身、白色镂空五官、怀抱小鱼、配樱花。本方案把这套语言提取为三条视觉基因，并贯穿全部资产：

1. **扁平色块，不描边、不渐变、不投影**——IP、Logo、插画主体全部平涂珊瑚红，靠白色镂空出五官。
2. **圆润几何，端点圆角**——所有图标线条端点、转角均为圆角，呼应"温暖但不幼稚"。
3. **珊瑚红 + 暖米白双色世界**——主色只有珊瑚红一族，中性一律暖灰，背景暖米白；薄荷绿只在背景光斑里微量出现。

> 这是**收钱工具**，不是营销页：可爱体现在配色、圆角和 IP 气质，**不**降低信息密度、**不**模糊按钮含义。

## 二、已敲定的色彩系统

### 2.1 品牌主色 · 珊瑚红

| 名称 | 色值 | 用途 |
|---|---|---|
| 珊瑚红（基准） | `#E8635C` | 按钮渐变、选中态、品牌图形 |
| 珊瑚-浅 | `#EC7F79` | 渐变浅端 / hover |
| 珊瑚-深 | `#BE514B` | ≥24px 装饰图标、强调边框 |
| 珊瑚-文字 | `#A83A32` | **白底上所有珊瑚色文字**（价格、强调词） |
| 珊瑚-浅底 | `#FDF3F2` | hover / chip / 选中浅底 |
| 珊瑚-中底 | `#FCE9E8` | 更深一档强调底 |
| 深暖墨 | `#38140E` | **珊瑚实底/渐变上的文字（不是白字）** |

**两条硬规则（开发与设计都必须遵守）：**
- ❌ 珊瑚红 `#E8635C` 不能当文字用（白底仅 3.30:1），要珊瑚色文字用 `#A83A32`。
- ❌ 珊瑚底上不能压白字（3.30:1），按钮文字用深暖墨 `#38140E`。

### 2.2 主色渐变

hover: linear-gradient(135deg, #ED7C76, #F0968F)

## 三、图标系统

### 3.1 风格与用法
- **线性图标**：`viewBox="0 0 24 24"`，`stroke-width:1.5`，圆头圆转角，与 Element Plus 图标视觉重量一致。
- **颜色跟随上下文**：所有线性图标用 `stroke="currentColor"`，由父级文字色控制——正文内联跟随文字，次要场景设 `#756E69`，激活态设 `#A83A32`，禁用 `#9A938C`，大尺寸装饰用 `#BE514B`。
- **尺寸**：内联 16px / 按钮内 18px / 导航 tab 20px / 空状态 40–48px。
- 单个 SVG 文件，不做雪碧图、不做图标字体。

## 四、品牌 IP 形象（`ip/`）

| 文件 | 规格 | 用途 |

## 十、排版、圆角、动效（确认值）

- **字体**：`Inter, -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`，单字族靠字重分层；数字/时间用等宽。
- **字号**：`11/12/13/14/15/16/20/22/24/48`；行高正文 1.6、标题 1.3。
- **圆角**：6 / 8 / 12 / 16（卡片封顶）/ 20 / 9999（按钮胶囊）。
- **间距**：`4/8/12/16/20/24/32/40/48`。
- **动效**：主曲线 `cubic-bezier(.16,1,.3,1)`；时长 快120 / 中200 / 慢320ms。禁用回弹、禁用 hover 缩放、禁用无意义装饰动画，并提供"降低动态效果"降级。

## 十一、加载动效建议（CSS 可实现）

`empty-loading.svg` 已给出静态造型（虚线环 + 珊瑚弧 + 端点圆点）。落地时用 CSS 让它旋转即可，无需 Lottie：

```css
.loading-spinner { animation: spin 1s linear infinite; }
@keyframes spin { to { transform: rotate(360deg); } }
@media (prefers-reduced-motion: reduce) { .loading-spinner { animation: none; } }
```
